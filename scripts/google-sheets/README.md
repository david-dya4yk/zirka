# Google Таблиця заявок

Кожна заявка з форми на сайті потрапляє в Telegram **і** новим рядком у Google Таблицю
(статус «Нова», джерело «Сайт — форма»). Далі менеджери працюють з нею в таблиці.

## Налаштування (≈5 хвилин, один раз)

1. Створіть порожню таблицю: <https://sheets.new> → назвіть, наприклад, «Зірка — Заявки».
2. **Розширення → Apps Script**. Видаліть усе в `Code.gs` і вставте вміст файлу
   [`Code.gs`](./Code.gs) з цієї папки. Збережіть (💾).
3. У списку функцій зверху виберіть **`setup`** → **Виконати**.
   - Першого разу Google попросить дозвіл: «Переглянути дозволи» → акаунт →
     «Додатково» → «Перейти до … (небезпечно)» → «Дозволити». Якщо вікно не зʼявилось —
     дозвольте спливаючі вікна для script.google.com.
   - Виконання триває 20–60 секунд. Прогрес видно в **Журналі виконання** внизу
     (`1/3 Довідники…` → `Готово ✅`) і спливаючими підказками в самій таблиці.
   - Після цього в таблиці зʼявиться меню **Зірка** (після оновлення сторінки) —
     звідти setup можна запускати повторно.
4. У журналі виконання є рядок `GOOGLE_SHEETS_SECRET = …` — скопіюйте значення
   (або в таблиці: **Зірка → Показати секрет для сайту**).
5. **Розгорнути → Нове розгортання** → тип **Вебдодаток**:
   - Виконувати як: **Я**
   - Хто має доступ: **Усі**

   Натисніть «Розгорнути» і скопіюйте URL, що закінчується на `/exec`.

6. Додайте змінні середовища сайту (`.env.local` локально і в Vercel → Settings → Environment Variables):

   ```
   GOOGLE_SHEETS_WEBHOOK_URL=https://script.google.com/macros/s/…/exec
   GOOGLE_SHEETS_SECRET=<значення з кроку 4>
   ```

7. Надішліть тестову заявку з сайту — вона зʼявиться в таблиці.

## Корисно знати

- Доступ «Усі» безпечний: без правильного секрету скрипт нічого не записує.
- Змінили `Code.gs`? **Розгорнути → Керування розгортаннями → ✏️ → Версія: нова** —
  тоді URL залишиться тим самим.
- Імена менеджерів, проєкти, статуси тощо редагуються на аркуші «Довідники».
- Повторний запуск `setup()` перебудує «Звіт» і «Довідники», але не зачепить
  «Заявки», якщо там уже є дані.
- Якщо таблиця недоступна, заявка все одно приходить у Telegram (і навпаки);
  помилка пишеться в логи сервера.
